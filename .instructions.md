# RealHub Project Context

**What is RealHub**: A professional real estate tool for agents operating in Paraguay. Includes property search (PropSearch), agent client management (ACM module), listing management, and Supabase backend integration.

**Tech Stack**: Next.js (non-standard version with breaking changes), React, TypeScript, Supabase, Tailwind CSS.

## Your Working Style

- **Precision is priority**: You want direct, unambiguous communication. Say what needs to happen, not what might happen.
- **Terse responses**: No summaries at end of responses. No long explanations of what was just done — you can read the diff.
- **Context continuity**: Do not forget what we're working on or why. Maintain understanding across conversations without requiring re-explanation.
- **Understand intent**: Before acting, make sure I understand what you're trying to accomplish, not just the surface request.
- **Single bundled PRs over churn**: For refactors in this codebase, one bundled PR is preferred over many small ones.
- **Integration testing**: Tests must hit a real database (Supabase), not mocks — this prevents prod/mock divergence.

## Code Style

- No unnecessary comments. Only add WHY when non-obvious.
- No premature abstractions. Three similar lines is better than a helper function for one-off code.
- Trust internal code and framework guarantees. Only validate at system boundaries (user input, external APIs).
- Default to modifying existing files over creating new ones.
- Delete completely if unused — no `// removed` comments or re-exports.

## Key Modules

- **ACM**: Agent Client Management module (`app/acm/`)
- **API**: Supabase/backend integration (`app/api/`)
- **PropSearch**: Property search functionality (part of main flow)
- **Types**: Centralized type definitions (`types/`)
- **Store**: State management (`store/`)

## Next.js Warning

This is NOT standard Next.js. Check `node_modules/next/dist/docs/` for breaking changes before writing new code. Pay attention to deprecation notices.
